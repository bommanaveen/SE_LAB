## Q23 - Commit and Push Experiment
You cloned a repository earlier, and now another collaborator has
made changes to it. You need to pull the latest changes from GitHub
to keep your local copy up to date.
Tasks:
 Clone a repository (from previous questions).
 Ask a collaborator to make a change and push it to the GitHub
repository.
 Use git pull origin main to pull the latest changes.
 Verify that the changes made by your collaborator appear in
your local repository.

This section demonstrates staging, committing,
and pushing changes using Git and GitHub.
